## What it does

`main.ts` is a small deterministic program that writes one line of plain
text — the phone battery's final text message to the charger it waited for
all day — to `/output/entry.txt`. The line is 180 characters, one line, and
the same on every run: no input, no network, no randomness.

> waited all day by the outlet while you charged your vape first. 1% now. tell the apps i loved them, tell wifi it was never its fault, and tell spotify it knows EXACTLY what it did.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
